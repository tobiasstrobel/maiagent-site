Privacy Policy – mAIagent Mail Bridge

Last updated: 24 October 2026

mAIagent is a personal, local desktop application that connects to Gmail via the Gmail API so the owner can process selected emails with a local AI agent.

Data access

With your consent, the app may read and send email on the authorized Gmail account (OAuth scope https://www.googleapis.com/auth/gmail.modify), limited to messages needed for that workflow.

Data storage and processing

  • OAuth tokens are stored only on the owner’s local machine.
  • Mail content may be processed locally (for example Open WebUI / Ollama on the same Mac).
  • No mail data is sold or shared with third parties by this app.
  • Google user data is not transferred to external servers except as needed to talk to Google’s Gmail API.

Who can use it

This app is for personal use by the developer/owner only. It is not offered as a public product.
